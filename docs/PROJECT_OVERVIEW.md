# Tan & Top Wedding Website — Project Overview

## Purpose

Static, read-only bilingual wedding website for guests to quickly access trusted wedding information on mobile and desktop.

Primary content:

- Schedule
- Venue and Google Maps
- Gallery placeholders
- FAQ
- LINE Official Account support page

## Core product rules

- Keep current route structure only (Thai default + `/en` English routes).
- No Accommodation or Dress Code page.
- No RSVP, form, chatbot, API routes, server actions, database, auth, analytics, or middleware locale redirects.
- LINE is a supporting channel, not a main nav destination.

## Naming and content rule

Visible naming must be bride-first:

- `Tan & Top`
- `Narueporn & Theerut`

## Visual direction

Minimal, elegant, classy, warm, premium, modern Thai hotel wedding style.

The site must feel like a minimal luxury wedding invitation, not a documentation page or generic template.

## Quality priorities

1. Mobile-first readability and polish (375/390/430/768).
2. Strong hierarchy and refined typography.
3. Practical guest clarity on Schedule and Venue.
4. Curated, intentional placeholder styling in Gallery.
5. Complete FAQ answers in both Thai and English.
